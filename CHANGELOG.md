# Changelog

## 0.1.1 Beta — 2026-10-22

- Added a native contextual menu to the DjVu reader for Copy, Select All, and Find.
- Improved DjVu rendering, cancellation, outline loading, and search navigation.
- Intel x86_64/macOS 26 beta validation completed locally with 24 passing tests.

## 0.1.0 — 2026-10-22

- Native macOS PDF and DjVu viewing with thumbnails, navigation, search, and recent documents.
- Vendored DjVuLibre-backed lazy rendering and DjVu-to-PDF export with cancellation and bounded caches.
- Preview-inspired welcome window, toolbar, sidebar, and light/dark appearance support.
- Intel x86_64/macOS 26 build and XCTest validation completed locally.
- Public release signing, notarization, Apple Silicon verification, PDF-to-DjVu, OCR, annotations, and the root application license remain incomplete.
