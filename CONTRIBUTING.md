# Contributing

Use Xcode 26.5 on macOS 26 and an Intel x86_64 Mac for the currently supported build. Do not add proprietary Preview resources, private APIs, or unapproved dependencies. Keep DjVuLibre and JPEG notices intact.

Before opening a pull request, run the build and XCTest commands in `Documentation/testing.md`, describe any environment-specific warnings, and update the relevant documentation when behavior changes. Keep fixtures and temporary test output inside the repository's test-controlled locations.
