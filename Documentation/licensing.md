# Licensing status

The repository currently has no selected root license for the PreViewer application. This is intentional and requires a maintainer decision before a public release; no license is inferred from the presence of third-party code.

The vendored DjVuLibre 3.5.30 code is GPL-2.0-or-later. The bundled JPEG implementation carries separate IJG and BSD-style notices. Copyright and license texts are preserved in `Vendor/DjVuLibre/`, including `GPL-2.0.md`, `COPYRIGHT.md`, `JPEG-LICENSE.md`, and `JPEG-IJG-LICENSE.md`. The build copies the notices into the application bundle.

Distributing a binary linked to DjVuLibre requires a GPL-compatible licensing decision for the combined work and the corresponding-source obligations described by GPL-2.0-or-later. The maintainer must approve the application license, source-offer method, and release notices before distribution. This document is a status note, not a license grant.
