# Preview UI study

`Documentation/UIStudy`, `Documentation/Toolbar`, and `Documentation/Welcome` contain read-only observations and screenshots of Apple's Preview and the corresponding PreViewer iterations. They document native `NSWindow`, `NSToolbar`, sidebar, Liquid Glass, and welcome-window behavior using public APIs only.

These studies are historical research. They do not include Apple resources or private framework calls, and they do not override the current architecture documentation.
